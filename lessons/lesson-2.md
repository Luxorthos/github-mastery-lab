# Lesson 2: Browser-Based Development

## What I Learned

- GitHub can provide a code editor through the browser.
- A branch isolates my work from the main project.
- A commit records a meaningful project change.
- A pull request allows a change to be reviewed before merging.

## My Workflow

Repository → Branch → Edit → Commit → Pull Request → Review → Merge

## Safety Principle

I will never commit passwords, API keys, patient records, or private credentials.
